# taleus CLI stories

`taleus` is Taleus on the command line: for testing, evaluating and debugging Taleus, not the way
most people will keep tallies. It is a client of `taleus-model` like the phone app, over a Sereus
node kept in a folder (`taleus-sereus/node`). These stories are deliberately few and short; each
is an example session. The command reference is [`design/specs/cli/commands.md`](../../specs/cli/commands.md).
