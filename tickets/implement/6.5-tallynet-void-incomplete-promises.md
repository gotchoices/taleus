## Context (background — the Phase 1 code already embodies all of this)

**What's wrong:** a lift whose promise phase never completes (a needed participant dies before promising) stays permanently `pending`, every promiser holding credit forever. Reproduction: `consensus-timeout.test.ts` § "a needed party that never returns" (`line(2)`, route `0→1`, `voters:[0]`, link dropped) — node 0 the sole voter on an incomplete set; its recovery loop abandons → `pending`. After this ticket that case **voids** (hence the Phase 2 re-point).

**Distinct from the dead-voter case** (must stay `pending`): `testing/consensus.test.ts` § "a dropped push on the only path stalls" (~:400) — the voter is beyond the dropped link and never receives the record. A node that never holds the record cannot vote. Unchanged.

**Design decisions (all implemented):** (1) a void's preimage binds the immutable core only, always — so `NC` verifies on arrival, needs no side pool, and a forged `NC` drops `forged`. (2) a void majority settles (`rejected`) from the voter set regardless of promise-set completeness; a commit majority still needs the complete set; same `settles(count)` formula (strict-majority floor AND method threshold) both sides. (3) the record reaches reachable voters through existing push/pull/recovery — no new transport; a voter majority that never hears stays `pending`. (4) each voter acts at its own deadline; recovery timer armed at `expiry + skewGraceMs`; classification gate uses raw `anyCodeExpired`.

## Edge cases (covered by the DONE unit tests; re-cover in the e2e/tallysim additions)

- Voter that is also the dead participant (P+V that never promises): signs `NP` first (ordering guard) → `rejected` globally. ✓ unit test.
- Voter set of 1 on an incomplete set: the sole voter's `NC` settles void. ✓ unit test.
- Late promise after some voters voided: their `NC` stands (verified over the core). 
- A voter that committed `C` before the deadline while others void: settle by majority; the **safety** scenario (set completes just before expiry, voter majority commits) must show **no** premature void — ADD in e2e.
- A forged `NC` never counts: fails verification on arrival, dropped `forged`. ✓ unit test (garbage-NC).
