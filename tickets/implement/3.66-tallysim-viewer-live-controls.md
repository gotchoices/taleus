Form sections (field keys are the exact `tallysim` generator/capacity param names — verified):
- **Generator** `selectField` (`uniform`/`scale-free`/`clustered`/`small-world`) + per-generator numeric params,
  shown dynamically (rebuild a `genParamsHost` on generator change, hold a `Map<string,HTMLInputElement>`):
  `uniform → meanDegree`; `scale-free → edgesPerNode`; `clustered → communityCount, meanIntraDegree, bridgeCount`;
  `small-world → neighbors, rewireProbability`. Plus shared `entityCount` and `seed`.
- **Capacity** `selectField` (`unlimited`/`constant`/`uniform`/`lognormal`) + its params (rebuild a `capParamsHost`):
  `constant → limit`; `uniform → min,max`; `lognormal → mu,sigma`; `unlimited → none → {kind:'unlimited'}`. The
  `CapacityDistribution` union is `{kind:'constant';limit}` / `{kind:'uniform';min,max}` / `{kind:'lognormal';mu,sigma}`.
- **Conditions** (optional, all blank by default → omit): `sleepingFraction, lateFraction, dropFraction,
  lateLatencyMs, conditionsSeed`, and a constant `latency` → `{kind:'constant', value: latency}`. Build a
  `ConditionsSpec` only from the fields the user filled; return `conditions: undefined` when none → `buildScenario`
  skips it. When any condition is set, default `conditionsSeed` to 0.
- **Budget** (optional): `initialBudgetMs, perHopBudgetMs` → `BudgetParams` (omit when both blank).
- **Query**: `amount, depth`; numeric `from`/`to` inputs are the **source of truth** (editable fallback for
  no-WebGL / no-click) + a small picked readout line reflecting them. Clicks write into the inputs; Run reads them.
  `from === to` allowed.
- **Buttons**: **Generate**; **Run** (enabled only when `generated && !running && from&&to set`); **Cancel**
  (enabled only while running); **Download trace** (enabled after any completed run).

Controls behaviour (design worked out — follow it):
- `readParams(): LiveRunParams` off the DOM. `from`/`to` via a `readOptionalNum(input)` helper (blank → undefined).
- **Generate**: `const scenario = buildScenario(readParams())`; **store `generatedScenario = scenario`** (so Run and
  the post-cancel regen reuse the *exact* network source — the materialised net must match the header's source);
  `worker.postMessage({type:'generate', scenario, runSeed: DEFAULT_RUN_SEED})`; status "Generating network…".
  `materializeNetwork` throws on bad params **inside the worker** → surfaces as an `error` phase `generate` msg (not
  a sync throw).
- **On `network` msg**: `keptSnapshot = msg.snapshot`; `materializedNetwork = networkFromSerialized(msg.snapshot.network)`
  (import `networkFromSerialized` from `tallysim`); if **not** a silent-regen, `view = liveHost.renderNetwork(network)`,
  then `view.onNodeClick(pick)` + `syncPicked()`; set `generated = true`.
- **Run**: `scenario = buildScenario(readParams())`, then **`scenario.network = generatedScenario.network`** (reuse
  the snapshot source); `query = buildQuery(readParams())` (throws if from/to unset — guarded by the enable rule);
  store `runScenario = scenario`; reset `runIndex`/`runHeader`; `worker.postMessage({type:'run', scenario, query})`.
- **On `header`**: `runIndex = createTraceIndex(msg.header, materializedNetwork)` (import `createTraceIndex` +
  `TraceIndexBuilder` from `../core/trace-index.js`). **On `event`**: `runIndex?.add(msg.event)`.
- **On `done`**: `running=false`; `deanon = createDeanonymiser(materializedNetwork)`;
  `conditions = compileConditions(materializedNetwork, runScenario.conditions ?? {}, runScenario.conditionsSeed ?? 0)`;
  `routeSource = { routesForSession: code => code === msg.sessionCode ? msg.routes : undefined }`. Then **if
  `runIndex.timeBounds() !== undefined`** → `liveHost.mountReplay({index: runIndex, deanon, conditions, routeSource,
  autoplay: true})`; **else** (zero-event degenerate) `liveHost.mountDisabledReplay()`. Set a terse status
  (route count / "No route found" / "Self-payment loop: N route(s)." when `query.from === query.to`). Record
  `lastRun = { header: runIndex.header, snapshot: keptSnapshot, events: runIndex.allEvents() }` for download.
- **On `error`**: phase `generate` → `generating=false; generated=false`; phase `run` → `running=false`; show
  `"<phase> failed: <message>"`. The worker swallows its own errors into this msg (never rejects), so no re-create.
- **Cancel**: `worker.terminate(); worker = makeWorker()` (fresh worker → **lost network scope**). Then to keep Run
  usable without a visible re-render, **silently re-generate**: set a `silentRegen` flag and
  `worker.postMessage({type:'generate', scenario: generatedScenario, runSeed: 0})`; the next `network` msg only
  refreshes `keptSnapshot`/`materializedNetwork` (no `renderNetwork`), preserving the drawn graph + picks. (This is
  the deliberate cancel design; if a reviewer prefers, the simpler alternative is to invalidate and force a manual
  re-Generate — document whichever you ship.)
- **Download trace**: `[serializeTraceLine(lastRun.header), serializeTraceLine(lastRun.snapshot),
  ...lastRun.events.map(e => serializeTraceLine({kind:'event', event:e}))].join('\n') + '\n'` → `Blob` →
  `URL.createObjectURL` → hidden `<a download>` click → `revokeObjectURL`. Reuse the **kept** snapshot (byte-identical
  to the worker's). Reloading via the File tab must animate identically.
- **Worker creation** `makeWorker()`: guard `typeof Worker === 'undefined'` and a thrown `new Worker(...)` (module
  worker unsupported) → show a clear panel error + disable the buttons (never a blank page). Else
  `new Worker(new URL('./sim-worker.ts', import.meta.url), {type:'module'})` (`.ts` so Vite resolves it; it is a
  plain string to `new URL`, so `tsc` NodeNext does not apply extension rules). Wire `w.onmessage` →
  `handleMessage(e.data)` and `w.onerror` → log + generic panel error. **Create eagerly at mount** for an immediate
  clear error (one idle worker is fine for a dev tool).
- **`invalidate()` (exposed)**: `generated=false; view=undefined; updateButtons()` — the shell calls it when a
  file/sample load replaces the view. A **local** structural-field change (generator / any gen param / entityCount /
  capacity kind / any cap param / seed) calls an internal `invalidateGenerated()` that sets `generated=false` but
  keeps `view`. Conditions / budget / amount / depth / from / to do **not** invalidate.
- `syncPicked()`: `view?.setPicked(from!==undefined ? entityName(from) : undefined, to!==undefined ? entityName(to)
  : undefined)` (import `entityName` from `tallysim`); update the readout; `updateButtons()`. `pick(nodeKey)` toggles
  a `pickTarget: 'from'|'to'`, writes `Number(nodeKey)` into the matching input, then `syncPicked()`.

Imports available from `tallysim`: `compileConditions, entityName, networkFromSerialized, serializeTraceLine`,

## Edge cases & interactions
- **Determinism**: same generator+params+seed ⇒ byte-identical network and trace; a downloaded live run reloaded via
  File animates identically (it replays recorded events, does not re-run).
- **Large live networks**: generation + discovery are in the worker; show "running…" + allow Cancel (terminate).
- **from === to**, **< 2 entities / no edges**: render the closed-loop / empty result without throwing (the worker
  tolerates these and may emit **zero** events → the `done`-handler's `mountDisabledReplay` branch + terse status).
- **Worker failure / unsupported environment**: clear panel error, never a blank page.
