Fourth viewer ticket. Replay (prior ticket) animates a *recorded* trace. This ticket adds the **second
source**: generate a network and run a live simulation in the page, streaming its trace events into the same
replay view. `tallysim`'s core is platform-neutral (its `no-node-globals` guard proves it is browser-safe),
so the real engine runs in-browser — no server.

## Architecture

### Sim Web Worker (`src/live/sim-worker.ts`)

Run the simulation **off the main thread** so a large network's discovery does not freeze the UI:

- The worker imports `tallysim` and builds a run: a generator from `src/live` params → a `Network`;
  `buildSimNetwork(network, conditions, conditionsSeed, traceSink, options)`; then `runQuery(sim, {from, to,
  amount, depth})` (or `issueQuery` + `clock.runUntilIdle()`), with a **trace sink** that forwards each
  `TraceEvent` to the main thread via `postMessage` as it is emitted.
- Build the full trace envelope so the live run feeds the **exact same** `trace-index`/`timeline` path as a
  loaded file: emit a `header` (reuse `buildTraceHeader` with the `SimScenario`, run seed, and the query's
  `TraceQueryEntry`) and the `network` snapshot first, then stream events. Reusing `makeTraceWriter`'s
  header/network/event sequencing keeps the live and file formats byte-compatible (and makes "save this live
  run to a trace file" trivial — offer a download).
- The main thread feeds the streamed header/network/events into the incremental `trace-index` builder
  (scaffold-core) and lets the timeline replay them — live events animate as they arrive, and the finished run
  is scrubbable like any trace.

### Live-run controls (`src/live/controls.ts`)

- Pick a **generator** (`uniform` / `scale-free` / `clustered` / `small-world`), its numeric params, the
  capacity distribution (`unlimited` / `constant` / `uniform` / `lognormal`), and a **seed**. Optionally the
  network **conditions** (latency / drop / sleeping / late fractions + conditions seed) and the discovery
  **budget**.
- **Click two nodes** on the rendered graph to set payer (`from`) and payee (`to`); set the amount and depth;
  **Run**. The graph-view's node-selection state is the input here — compose with it.
- Flow: generate → render the static network (graph-view) and settle the worker layout → arm the sim worker →
  on Run, stream events into replay. Re-running a different query on the same network reuses the rendered graph
  and layout (one `InMemoryNetwork` serves many queries; no balances move this tier).
- Offer **"download trace"** of the live run (serialise via `serializeTraceLine`) so a live run becomes a
  shareable file the file-source path reloads identically.

## Edge cases & interactions

- **Determinism**: same generator + params + seed ⇒ byte-identical network and (per `tallysim`) byte-identical
  trace. A live run then downloaded and reloaded must animate identically. Note the subtlety that a session
  code is minted inside `discover()`; the live path learns it from the first event stream (it does not need
  `cli/trace.ts`'s two-pass trick because it animates the one real run it is observing, not reproducing it).
- **Large live networks**: generating and settling a many-thousand-node network must keep the UI responsive —
  generation + discovery run in the worker; only positions and events cross to the main thread. Discovery is
  ~O(network) per query (a `NOTE:` in `tallysim`'s sim-runner flags this) — show a "running…" state and allow
  cancel (terminate the worker) for a long run.
- **from === to** (self-payment / clearing-style loop): the harness does not throw; the run yields a circular
  plan or empty — must animate and render the closed-loop case (replay ticket handles the loop rendering).
- **< 2 entities** or a generator producing no edges: the run completes with an empty result, shown as such.
- **Sleeping/late/dropped conditions chosen in the UI**: the live run's header carries the `conditions` +
  `conditionsSeed`, so the replay ticket's sleeping/late styling and prune-reason display work unchanged.
- **Worker failure / unsupported environment**: surface a clear error (not a blank page); if Web Workers or
  module workers are unavailable, say so.
