**Design decisions / deviations a reviewer should know (document these in the review handoff):**
- **`negotiatePlan` lives only in `DiscoveryHooks`, not in `ParticipantOptions`.** The original
  ticket listed it in both; keeping one home (hooks, where all negotiation lives) avoids two sources
  of truth (DRY). `ParticipantOptions` is `{ maxQueryAgeMs, maxDepth, minSessionMs }`.
- **`annotateReturn` runs at BOTH `enter` (for self/peer-match plans) and `reenter` (for sub-query
  plans)** — i.e. everywhere this node prepends itself, matching "called where ChipNet calls
  prependMatch". The original ticket spelled it out only for `reenter`.
- **Accumulate-and-dedupe plan model.** `context.plans` holds the node's concluding plans (self
  already prepended), deduped by path-nonce via `planKey`. Match plans are added at `enter`;
  candidate plans are folded from each candidate's durable `lastResponse` every round (idempotent).
  This is how "no plan lost / not double-counted / restart-safe" is achieved — the durable
  `lastResponse` is the single source of truth; the in-flight table is only an optimisation over
  re-deriving from it. (`planKey` dedupe-by-path has a NOTE tripwire in the code.)
- **Prune-reason mapping** (document in handoff): `cycle` at enter; `failed` (errored sub-query) and
  `no-reentrance` (completed, no reentrance) in the per-round prune; `max-depth` when concluding on
  depth; `expired` on a bad reentrance ticket; `timed-out` for still-outstanding candidates when
  concluding on satisfaction. Sleeping peers are KEPT across rounds (so late folding works), never
  pruned as timed-out mid-search.
- **`maxDepth` concludes (no throw)** when `context.depth >= query.maxDepth` (depth starts at 1 after
  enter; +1 per advancing reenter), pruning remaining candidates `max-depth`. ChipNet threw.
- **`random` (`RandomSource`) is accepted by the constructor but currently unused** — the
  participant's logic is deterministic (candidates sorted by nonce). Held for the engine. Confirm
  this is acceptable or wire it where a seed is genuinely needed.
