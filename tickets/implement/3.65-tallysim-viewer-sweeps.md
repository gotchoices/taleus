**Done:**

- **`src/core/sweep-data.ts` (pure, DONE + tested).** Extended beyond the scaffold-core parser with:
  - `readSweepJsonl(text)` / `readSweepCsv(text)` → `SweepTable` = `{ rows, columns }`. `columns` is
    `SweepColumn[]` carrying `{ name, role, kind, values, varied }` where `role ∈ 'dimension'|'param'|'seed'|'metric'`.
    JSONL captures roles from where a key sits (`params` → param, `metrics` → metric); CSV infers them from
    header position relative to the `seed` column. The old `parseSweepJsonl`/`parseSweepCsv` still exist as
    thin `.rows` wrappers (existing tests unchanged).
  - `defaultSelection(table)` → `{ xColumn, metricColumn, seriesBy }`. x = first **varied param** (prefers a
    connectivity-named one, regex `/degree|edgespernode|connect/i`); metric = first present of
    `pFoundGivenExists, pRouteExists, routeExistsCount, foundCount`; seriesBy = the dimension columns
    (`generator`,`capacity`) + every other varied param. **x may be any numeric column** (a *metric* like
    `meanDegree` is a valid x too — it is the "headline x-axis" — so the x picker must offer metrics, not only
    params).
  - `distributionFamilies(columns)` → groups `${f}.count/mean/.../p99` metric columns into
    `{ family, countColumn, subFields }`. A numeric tally like `pruneReasons.cycle` is **not** a family.
  - `meanPerCell(series)` → collapses repeated-seed points to one mean point per `(series, x)` cell.
  - `alignSeries(series)` → `{ x, columns:[{seriesKey, y:(number|null)[]}] }`: union x, `null` (a line gap) where
    a series has no point — never `0`.
  - `rowsToSeries` gained `spec.gapWhenZeroColumn`: a cell whose named column is `0`/absent contributes **no**
    point. **This is load-bearing and non-obvious:** `summarizeDistribution` reports `count: 0` with every
    scalar a finite **`0`** (not `Infinity`/`NaN`), so plotting `pathLength.mean` where `pathLength.count === 0`
    would draw a spurious `y = 0` unless the view passes `gapWhenZeroColumn: 'pathLength.count'`. The view MUST
    set this for a distribution sub-field — **except** when the chosen sub-field *is* `count` (there `0` is real).
  - Tests: `src/core/sweep-data.test.ts` (11 tests) cover role agreement across formats, defaults, families, the
    count:0 gap (both with and without the guard), `meanPerCell`, `alignSeries`.

## Edge cases & interactions (unchanged — the spec for the remaining UI)

- **Both record kinds**: read the columns present; offer only those metrics (`sweep-data` already classifies
  them — the view just filters by `role === 'metric'`). Do not assume one shape.
- **Non-finite values** (e.g. unbounded `maxFlow` → `null`/empty) are already read as absent by `sweep-data`, so
  `rowsToSeries` omits them (a line gap), never `0`.
- **Distribution-summary columns**: user picks the sub-field (default `mean`); `count: 0` is a gap (via
  `gapWhenZeroColumn`), never `0`.
- **Multiple seeds per cell**: **mean-per-cell** (`meanPerCell`); per-seed raw points are intentionally not
  scattered (documented, see above).
- **Single-value / empty sweep**: a one-cell file shows a single point (uPlot `points.show` is on); an
  all-gap/empty selection shows the chart's "nothing to plot" message; a malformed file shows a parse error in
  the panel.
- **CSV vs JSONL agreement**: pinned headlessly by `sweep-data.test.ts`; the view must not diverge.
