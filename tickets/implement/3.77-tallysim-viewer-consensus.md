### Landed (compiles; untested)

- **`core/trace-index.ts`**
  - `LiftResolver` interface + `createLiftResolver(lift)`: `entityOfMember(key)` reads the header's
    `lift.memberKeys` (already a `memberKey → entityId` map — no inversion needed); `tallyOfEdge(from, to)`
    returns the hop's tally via an **order-independent** pair key folded from the index-aligned
    `route` + `tallyPath` (hop `i` joins `route[i]↔route[i+1]` on `tallyPath[i]`). A circular lift's repeated
    originator sits on two **distinct** unordered pairs, so this is unambiguous.
  - `TraceIndex` gained `lifts()`, `liftFor(sessionCode)`, `liftByTransaction(txCode)`; `createTraceIndex`
    indexes `header.lifts ?? []` by both join keys. A v1 / discovery-only v2 trace ⇒ `lifts()` is `[]`.
- **`core/timeline.ts`**
  - Consensus types exported: `ConsensusEdgePhase` (`promised`|`committed`|`released`), `ConsensusNodePhase`
    (`promised`|`voted`|`settled`), `ConsensusDecision`, `ConsensusEdgeState`, `ConsensusNodeState` (with
    `vote?: 'C'|'NC'`), `ConsensusState` (`transactionCode`, `edges`, `nodes`, `decision?`, `settledTime?`,
    `unresolved[]`), and `ConsensusBinding` (`{ lift, resolver }`).
  - `ActiveSet.consensus?` added — **optional and omitted entirely unless a lift is bound**, so existing
    discovery `deriveActiveSet(...).toEqual({nodes,edges,pruned,foundPlans})` tests stay green (and Jest
    `toEqual` ignores `undefined` keys regardless).
  - `createTimeline` accepts `consensus?: ConsensusBinding`. The discovery loop now guards
    `if (isConsensusEvent(event)) continue` (a consensus event's `nodeId` is a **member key**, not an entity
    id — `entityId(memberKey)` would be `NaN`). `deriveConsensus(t)` recomputes the per-lift settlement state
    from scratch (so a backward scrub un-settles): promised edges, node phase ranks (promised<voted<settled),
    votes, `decision`/`settledTime`, and `unresolved` member keys (malformed-trace sentinel, surfaced not
    dropped). `consensusEdges()` maps decision → edge phases: **commit ⇒ every `tallyPath` edge `committed`**;
    **void ⇒ only promised edges `released`**; **no decision (in-flight/stalled) ⇒ promised edges `promised`**.

### Key facts the design relies on (don't re-derive)

- One lift per session (query → session → lift). Consensus events share the discovery session's `sessionCode`
  **and** carry `transactionCode`; `index.eventsForSession(code)` returns both, and the discovery loop guards
  the consensus ones out. Multiple settling queries = multiple sessions, each its own lift/route.
- `TraceLiftEntry` (from `tallysim`): `route: number[]` = `[from,…,to]` entity ids (circular ⇒ first===last),
  `tallyPath: number[]` = per-hop tally index (`route.length-1` entries), `memberKeys: Record<string,number>`
  = memberKey→entityId, `transactionCode`, `sessionCode`, `amount`.
- Consensus `TraceEvent` variants (from `tallynet/src/trace.ts`): `record-pushed {to, promiseCount,
  commitCount, ok}`, `record-received {from?}`, `promise-signed {signatureType:'P'|'NP'}`,
  `signature-rejected {reason}`, `referee-vote {decision:'C'|'NC'}`, `settled {decision:'commit'|'void'}`,
  `resources-released {success}`. All carry `transactionCode` + `nodeId` = emitter's member key.

## Edge cases & interactions (unchanged from the original spec — verify in tests/manual)

- **v1 / discovery-only v2** (no `lifts`): no consensus phase, no new UI; discovery replay byte-for-byte as
  before. (Core already guards: `lifts()` empty ⇒ no binding ⇒ no `consensus` key.)
- **Void after some promises:** only the promised edges flash and clear; side list shows `voided`; no edge
  stays solid.
- **Circular lift** (`route[0]===route[last]`): animates as a closed loop; the shared originator carries its
  promise and its vote and settles once; the `(from,to)→tally` resolver already handles it (two distinct
  pairs).
- **Stalled (pending) lift:** no `settled` → route stays partially-promised, badge `stalled`; fabricate no
  settle. (Core already does this.)
- **Backward scrub across commit/void:** recompute-from-scratch yields the correct partial state. (Core.)
- **Node both relays discovery and participates in consensus:** discovery (round) and consensus overlays
  compose; consensus (later in time) wins past settlement. Document the compose order.
- **Member key not in `memberKeys`** (malformed): surfaced in `consensus.unresolved`, never silently dropped.
- **Multiple lifts in one trace:** each `transactionCode` animates on its own route (its own session); select
  one to isolate it.
