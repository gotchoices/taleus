## Proceed

`ConsensusNode.proceed(...)` delegating to a new `TrxParticipant.proceed(...)`:

```ts
// ConsensusNode (engine.ts) — thin delegate
proceed(args: { plan, query, payload, ttlMs? }): Promise<TrxRecord<TTerms, TPayload>>
// TrxParticipant (participant.ts)
async proceed(args): Promise<TrxRecord> {
	const transactionCode = generate(args.ttlMs ?? DEFAULT_TTL, { now: this.clock.now(), random: this.random })
	const record = mintRecord({ plan: args.plan, query: args.query, payload: args.payload, transactionCode })
	return this.update(record)   // === start(): classifies ourPromiseNeeded, signs our P, pushes
}
```

- `start(record)` is already `update(record)` (`engine.ts:77`). So `proceed` = mint the self-expiring
  transaction code, `mintRecord`, then `update`. The state machine (`advanceState` →
  `ourPromiseNeeded` → `castPromise`, `participant.ts:508,511,544`) signs the originator's **P** and
  pushes. Nothing new in the push/sign plumbing.
- **The caller chooses the plan.** `discover` already returns plans **best-first** (`originator.ts:207
  rankPlans`), so "choose a plan" = the `taleus-core` binding passes `plans[0]` (or any ranked plan).
  Keep `proceed` thin — it does not rank.
- **Add a `RandomSource` to the node.** `ConsensusNodeDeps` (`engine.ts:26`) and `TrxParticipantConfig`
  (`participant.ts:63`) have `clock` but **no** `random` today. Add `random: RandomSource` to both (import
  `RandomSource` from `../crypto.js`), thread it through the `ConsensusNode` constructor into
  `TrxParticipant`, and store it as a private field. Wire it in the harness: `buildConsensusNode`
  (`network.ts:288`) passes `random: this.random` (the network already holds a `SeededRandom`). Pick a
  `DEFAULT_TTL` const (600_000 ms, matching `buildLift`/`consensus.test.ts`); let `ttlMs` override.

## Abort — RESOLVED (the original blueprint was wrong)

**The bug in the old plan.** It said "abort = sign our `NP` on our own member → voids by the any-`NP`
rule." But `proceed`→`start` **already auto-signs the originator's `P`** (shown above). Signing `NP`
*after* `P` is **equivocation**: `mergeSignature` (`participant.ts:273-279`) keeps the first face (`P`) and
rejects the `NP` at every peer. The local record would have both (so it voids **locally**: `getRecordState`
returns `rejected` on any `NP`, `participant.ts:419`), but every peer keeps only the originator's `P` and
goes on to **commit** — the originator voids while the route commits. **Atomicity violation. Do not ship
the old design.**

**The resolution.** `abort` signs the originator's `NP` **only when the originator has not yet signed any
promise-phase signature** (neither `P` nor `NP` by `self`). Then the `NP` is the originator's sole
promise-phase face — no equivocation — and it voids cleanly everywhere (any `NP` → `rejected`, applied the
same by every node and relay). Implement on `TrxParticipant` (where `store`, `self`, `sign`, `push`,
`promisePhaseComplete`, `weAre`, `weHaveSigned` are all in scope), delegate a thin `ConsensusNode.abort`:

```ts
async abort(transactionCode: string): Promise<void> {
	const record = await this.store.getRecord(transactionCode)
	if (!record) { this.log('tallynet consensus: abort on unknown transaction %s (no-op)', transactionCode); return }
	if (await this.store.isReleased(transactionCode)) { this.log('… abort after settlement %s (no-op)', transactionCode); return }
	if (!this.weAre(MemberTypes.participant, record)) { this.log('… abort by a non-participant %s (no-op)', transactionCode); return }
	if (this.promisePhaseComplete(record)) { this.log('… abort refused — every participant has promised %s', transactionCode); return } // principle 3
	if (this.weHaveSigned(record.promises)) { this.log('… abort refused — we already promised %s (NP would equivocate)', transactionCode); return } // atomicity guard
	await this.sign(record, 'NP', 'promises')  // participant.ts:627 — appends + persists our NP
	await this.push(record)                    // diffuse the void
}
```

- `promisePhaseComplete` is `private` on `TrxParticipant` (`participant.ts:467`) — abort lives in the same
  class, so it calls it directly. No need to make it public.
- **Consequence to document:** in the `proceed`=mint+start flow the originator signs `P` immediately, so a
  later `abort` is correctly **refused** (the atomicity guard fires). `abort` is usable only on a
  **seeded-but-unpromised** record — the test exercises this by seeding the store directly
  (`net.consensusStoreOf(name).saveRecord(record)` with empty `promises`) and then calling `abort`.
- This is **stricter** than principle 4's literal "abort before every participant has promised". Fully
  reconciling it would need either a seed-without-promise `proceed` variant or an "equivocation voids the
  lift" merge rule — **both out of scope** (merge rules belong to `tallynet-consensus-participant`, which
  has landed). Record this in the handoff as a known design refinement + flag for the reviewer.

## Tests (extend `testing/consensus.test.ts`, reuse its harness/idioms)

- **proceed, happy path**: build a plan by hand (or via `buildLift`'s record shape) with a `[P,V]`
  terminus; `proceed` → drive the clock → every node commits, each releases once. (If building a real
  discovered plan is awkward here, assert proceed against a hand-made plan; the full discovery→proceed path
  is Part 3's e2e.) Assert the originator's `P` is present and the record propagated.
- **abort voids a seeded-but-unpromised record**: seed the originator's store with a bare record (empty
  `promises`), `abort` → the originator signs `NP`, pushes → every node reads `void`, each releases once as
  failure.
- **abort refused after `promisePhaseComplete`**: drive a lift to the point every participant promised,
  then `abort` → no-op (no `NP` added, outcome unchanged, no second release).
- **abort refused after our own `P`** (the atomicity guard): `proceed` (signs `P`), then `abort` → no-op;
  the lift still commits.
- **abort no-ops** on an unknown transaction and on an already-released one.
- `yarn build && yarn test && yarn lint` green for `tallynet` (stream with `tee`).
