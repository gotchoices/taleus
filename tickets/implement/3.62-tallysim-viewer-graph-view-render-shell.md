## Remaining work

### `src/graph/render.ts` — the sigma renderer

Export `createGraphView(container, graph, palette)` → a `GraphView` with
`{ webglAvailable, setPalette(p), search(idText): boolean, clearSelection(), focusNode(key), destroy() }`.

**This is sigma 4.0.6 — a ground-up rewrite, NOT the sigma v2/v3 API. Do not trust older docs/memory.** The
facts below were dug out of the installed `.d.ts` and dist bundles; trust them:

- Construct: `new Sigma<TallyNodeAttributes, TallyEdgeAttributes>(graph, container, { settings, nodeReducer,
  edgeReducer })`. `MultiDirectedGraph<N,E>` is assignable to the expected `Graph<N,E,G>`.
- **Reducers still exist** and run *after* the built-in `DEFAULT_STYLES` (which map x/y/size/color/label from
  node attrs); a reducer returns `Partial<NodeDisplayData>` / `Partial<EdgeDisplayData>` merged on top. Put all
  dynamic styling in reducers (read a `palette` closure var + a precomputed capacity range + edge/node state).
- `EdgeDisplayData` fields to set: `size`, `color`, `zIndex`, `head` (arrow extremity), `path`,
  `parallelPath`, `parallelSpread` (number). **Built-in path names: `"straight"` (NOT `"line"`), `"curved"`,
  `"curvedS"`, `"step"`, `"stepCurved"`, `"loop"`. Built-in extremity names: `"arrow"`, `"bar"`, `"circle"`,
  `"diamond"`, `"square"`.** For the arrowhead set `head: 'arrow'`; for parallel-edge separation set
  `path: 'straight'`, `parallelPath: 'curved'`, `parallelSpread: ~0.35` — sigma auto-computes
  `parallelIndex`/`parallelCount` into edge *state* and curves parallels itself.
- `NodeDisplayData` fields: `size`, `color`, `label`, `labelColor`, `labelVisibility: 'auto'|'visible'|'hidden'`,
  `highlighted`, `x`, `y`, `zIndex`.
- **Edge capacity encoding** (satisfy the original ticket's explicit constraints):
  - `unlimited = !Number.isFinite(capStockToFoil + capFoilToStock)` → `color = palette.edgeUnlimited` and a
    **fixed moderate thickness that is NOT the finite-scale maximum** (this is the headline requirement: an
    `Infinity` edge must never look like a merely-large finite one). E.g. finite sizes 1..5, unlimited fixed 3.
  - finite → `total = capStockToFoil + capFoilToStock`; precompute finite `[minTotal, maxTotal]` across edges
    once at setup; `norm = log-normalize(total)`; `color =` tercile pick of `palette.edgeRamp`; `size =` 1..5
    by `norm`. A **zero-capacity direction still renders** (edge is present with its arrowhead — zero ≠ missing).
  - hover/selection (`state.isHovered || state.isHighlighted`) → `color = palette.highlight`, thicker, raised
    `zIndex`.
- **Node** reducer: `color = palette.node`, `label` from attrs, `labelColor = palette.nodeLabel`; search
  selection (`state.isHighlighted`) → `palette.highlight`, bigger, `labelVisibility: 'visible'`.
- **Hover tooltips**: `settings.enableEdgeEvents = true`. Listen `sigma.on('enterNode'|'leaveNode'|
  'enterEdge'|'leaveEdge', ({ node|edge, event }) => …)`; `event` is `MouseCoords` with viewport `x,y` — place
  an absolutely-positioned tooltip `<div>` inside `container` (the shell CSS makes it `position:relative`).
  Node tooltip: `Entity {id}`, `degree {graph.degree(node)}`. Edge tooltip: `tally {i}`, orientation
  `stock {s} → foil {f}`, and both directed capacities (render `Infinity` as `∞`).
- **Search / selection via built-in state** (keeps replay's future "lit" state separate so they compose):
  `view.search(idText)` → if `graph.hasNode(idText)`: clear prior `setNodeState(prev,{isHighlighted:false})`,
  `setNodeState(id,{isHighlighted:true})`, then centre the camera —
  `const dd = sigma.getNodeDisplayData(id); void sigma.getCamera().animate({x:dd.x, y:dd.y, ratio:0.3},
  {duration:400})` — and return `true`; else `false`. Do **not** touch `customEdgeState`/`customNodeState` —
  reserve those for the replay ticket.
- `setPalette(p)`: update the closure var, set `container.style.background = p.surface`, `sigma.refresh()`.
- **WebGL2 required**: before constructing Sigma, detect via
  `document.createElement('canvas').getContext('webgl2')`; if `null`, render a clear message element into
  `container` and return a stub `GraphView` with `webglAvailable:false` and no-op methods (no thrown error,
  no blank canvas).
- `destroy()`: `sigma.kill()` + remove the tooltip node.
- Camera `animate(...)` returns a `Promise` → prefix calls with `void` (eslint `no-floating-promises`).

Not headlessly testable (WebGL/worker). No jest here — the gate is `vite build` + a manual check.

    Show a header summary in the panel (generator, entityCount, tally count, query count).

  - **Marked seams** (comments) where the live-run and sweep source tabs will mount — this ticket wires only the
    file-load path.
