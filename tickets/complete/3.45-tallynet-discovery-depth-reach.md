## What this was

The simulator's virtual clock under-drained discovery's per-level completion cascade: its
`DRAIN_QUIET` constant (16 quiet microtask hops) was smaller than the cascade (~17–23 hops), so a
drain quiesced mid-cascade and the run loop fired an about-to-be-cleared round-budget timer. That
advanced virtual time to full budget and folded an instant answer one round late — making the sim
report discovery's reach as `2(L − 1)` instead of its true `maxDepth = L` (one round per level).

**Fix:** raise `DRAIN_QUIET` 16 → 64 (measured threshold 24; 64 is ~3× margin), then correct every
test and doc that had codified the `2(L − 1)` artifact as if it were real protocol behaviour. The
same premature-budget-timer fire was also the root cause of the divergence tracked by
`tallysim-sim-runner-concurrent-divergence` (seq 3.535); with the cascade fully draining, concurrent
and sequential sweep modes now produce byte-identical records.

See the implement commit (`git show 8f9673e`) for the full change set and the implementer's handoff.
