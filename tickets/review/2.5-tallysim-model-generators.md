# Review — tallysim network model + generators

Adversarial review pass over the **first** of three chained tickets that stand up the `tallysim`
package (network-model tier). This ticket built everything needed to *construct* a tally network as plain
serialisable data; it does **not** search it (that is `tallysim-oracle`, next). The oracle and runner
tickets sit in `implement/` and depend on this work via `prereq: tallysim-model-generators`.

All gates were green at handoff: `yarn workspace tallysim build && … lint && … test` → **76 tests pass,
lint clean, neutral build clean**; root `yarn build` integrates the package topologically (after
`tallynet`). Treat the tests as a **floor**, not a finish line.

## What was built (where to look)

New Yarn-workspace package `packages/tallysim` (unscoped `tallysim`), modelled on `tallynet`: ESM, strict
TS, tabs, single quotes, jest + ts-jest. One sibling dependency: `tallynet` (`workspace:^`), used only for
its seeded PRNG `SeededRandom` (from the `tallynet/testing` subpath export). Never depends on `taleus-core`.

- **`src/model.ts`** — `EntityId` (entities are index-based integers), `Tally`, `Network`, `NetworkMeta`,
  `FORMAT_VERSION`, and `serialize` / `deserialize`. The `Infinity` ↔ `null` sentinel for unlimited credit
  limits lives here (JSON can't carry `Infinity`). `deserialize` rejects an unknown `formatVersion`.
- **`src/capacity.ts`** — the directed-capacity model: `capFoilToStock`, `capStockToFoil`, `totalSwing`.
  Pure functions over a `Tally`. The scoping decision (omit trading-variable fees) is recorded in
  `docs/design.md` § Capacity model, with the forward pointer to `feat-tallysim-trading-model`.
- **`src/distributions.ts`** — `CapacityDistribution` (`unlimited` | `constant` | `uniform` | `lognormal`)
  and `drawCapacity`. Limits are non-negative integers (except `unlimited`); balance defaults to 0.
- **`src/generators/`** — `uniform` (Erdős–Rényi), `scaleFree` (Barabási–Albert), `clustered` (communities
  + bridges), `smallWorld` (Watts–Strogatz). Each is `(params, rng?) => Network`; `rng` defaults to a fresh
  `SeededRandom(params.seed)`. Topology is built first, then `shared.ts:materialize` orients each edge and
  draws its capacity.
- **`src/structure.ts`** — `degreeSequence`, `meanDegree`, `degreeHistogram`, `connectedComponents`
  (union-find; largest-component fraction).
- **`src/no-node-globals.test.ts`** — the platform-neutrality + determinism guard (greps for `Buffer`,
  `node:`/bare-builtin imports, `require`, `Math.random`, and wall-clock/timer globals).
- **`docs/design.md`** — canonical simulator design: Tiers, Model, Capacity model, distributions,
  Generators, PRNG, plus headed stubs for *Oracle*, *Metrics*, *Runner / experiments*, *Trace & replay*.

## Use cases to validate (the point of the tier)

- **Build a network, save it, reload it unchanged.** `serialize` → `deserialize` round-trips a finite
  network, an **unlimited-capacity** network (`Infinity` limits), a one-sided-unlimited tally, and an
  **empty** network, all byte-identical. Confirm `Infinity` survives as the `null` sentinel.
- **Reproducibility.** Any generator with the same `(params, seed)` returns a deep-equal `Network`; a
  different seed returns a different one. This is the determinism rule the whole simulator rests on.
- **Capacity identity.** For any tally, `cap(F→S) + cap(S→F) === stockCreditLimit + foilCreditLimit`; both
  directions non-negative; at a credit bound one direction is exactly 0; `unlimited` ⇒ `Infinity` both ways.
- **Generator fidelity.** `uniform` hits the requested mean degree; `scale-free` is heavy-tailed (a hub
  emerges); `clustered` has more intra- than inter-community edges and **exactly** the requested bridge
  count; `small-world` keeps mean degree `k`, is a pure lattice at `β=0`, and rewires ~`β` of edges.
- **Structure utilities.** Largest-component fraction = 1 (fully connected), 0.5 (two equal halves), 1/n
  (all isolated); degree counts both endpoints and counts a parallel edge twice.

## Known gaps / where to probe hardest (honest handoff)

- **Fidelity tolerances are statistical, not exact.** The `uniform` mean-degree test uses `toBeCloseTo(…,1)`;
  the `scale-free` hub test asserts `maxDegree > 5·meanDegree`; the `small-world` mid-β test asserts the
  rewired fraction is within `[0.35, 0.65]` at `β=0.5`. These are loose bands chosen to be seed-robust —
  scrutinise whether they are *tight enough* to actually catch a broken generator (e.g. an ignored seed, or
  a generator that silently produces the wrong distribution). They are a floor.
- **Small-world rewiring-fraction *measurement* can undercount.** The β tests measure rewiring by counting
  tallies whose undirected key is absent from the original lattice. A rewired edge can, by rare chance, land
  on a canonical key that a *different* lattice edge vacated, so it reads as "not rewired". This biases the
  measured fraction slightly low but does not affect the generated network's correctness. The β=0 (exact 0)
  and β=1 (>0.8) tests bound it; the mid-β band is deliberately wide because of this. Worth confirming the
  generator's own rewiring logic (`small-world.ts`) is correct independent of how the test measures it.
- **`clustered` community recovery is duplicated in the test.** `generators.test.ts:communityOf` re-derives
  the contiguous partition that `clustered.ts:partition` builds. If one drifts from the other, the
  "exactly bridgeCount" test could pass or fail for the wrong reason — check the two partition rules agree.
- **Degenerate configs return smaller-than-asked graphs rather than throwing.** `scaleFree` with
  `entityCount <= edgesPerNode` returns a complete graph; `clustered` with `<2` non-empty communities places
  no bridges; `uniform` with `entityCount=1` places no edges. These are documented in `docs/design.md`
  § Generators and tested, but confirm the chosen behaviour is what the oracle/runner tiers will want
  (vs. a throw). No exception is raised for "I asked for bridges but got none".
- **Capacity magnitude precision is the oracle's tripwire, not re-recorded here.** Capacities are JS
  `number`; a value above 2^53 loses integer precision. The `tallysim-oracle` ticket already owns this
  tripwire (it stores capacities in a `Float64Array`). Planned scenarios keep units small, so no code
  comment was added here to avoid a duplicate — flag if you think the model layer also needs the NOTE.
- **`randomizeBalance` is implemented but unused by any generator default.** Generators pass the caller's
  `CapacityDistribution` straight through, so `randomizeBalance` works, but the four generators as exercised
  in tests use `unlimited`. Non-zero starting balances across a generated network are tested only at the
  distribution layer, not end-to-end through a generator — a thin spot.
