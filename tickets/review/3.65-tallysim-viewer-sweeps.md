Review handoff for the **sweeps view** — the fifth and last viewer rendering tier. It adds a `Graph | Sweep`
mode toggle to the shell; in Sweep mode the developer loads a parameter-sweep file (or an embedded sample) and
gets a line chart of **one metric vs. one varied parameter, one line per series** (e.g. the chance a payment
routes rising with how densely the network is connected).

**Build + tests + lint are all green** (`yarn build && yarn test && yarn lint` in `packages/tallysim-viewer`;
86 jest tests pass, tsc clean, eslint clean). Treat the tests as a floor, not a ceiling — see *Known gaps*.

## What was already done before this run (verified, not re-touched)

The pure core, the palette, and the uPlot renderer landed in a prior (budget-interrupted) run and were left
green:

- **`src/core/sweep-data.ts`** (pure, 11 jest tests in `sweep-data.test.ts`) — reads both JSON-lines and CSV to
  a common `SweepTable` (rows + role-classified `SweepColumn[]`), with `defaultSelection`, `distributionFamilies`,
  `rowsToSeries` (+ `gapWhenZeroColumn` guard), `meanPerCell`, `alignSeries`. Non-finite **and**
  distribution-`count:0` values read as a line gap, never `0`.
- **`src/app/theme.ts`** — `Palette.seriesScale` (8-hue colour-blind-safe categorical set, light + dark columns).
- **`src/sweeps/chart.ts`** — the uPlot renderer (browser-only). One line per series, palette colours, relocated
  legend, `scales.x.time = false`, `points.show`, rAF-debounced `ResizeObserver`, empty-state message, uPlot CSS
  vendored as a string.

## What this run added (the UI wiring — the bulk of the review surface)

- **`src/sweeps/source.ts`** (new, pure) — `detectSweepFormat(fileName, text)` (extension first, then sniff) and
  `loadSweepText(fileName, text): SweepTable` dispatching to the `sweep-data` readers. Carries an embedded
  `SAMPLE_SWEEP` (12 oracle-style rows, 2 generators × edgesPerNode {1,2,3} × 2 seeds, with a `pathLength.count:0`
  cell) so the view is exercisable with no file. Error policy: a malformed JSONL line lets `JSON.parse` throw
  through to the view's status line; a valid-but-empty file is **not** an error (chart shows "nothing to plot").
- **`src/sweeps/view.ts`** (new, browser-only) — `mountSweepView({panelHost, chartHost, palette})` builds the
  file loader + the x-axis / metric / sub-field / series-by pickers (seeded from `defaultSelection`), and on any
  change assembles a `SeriesSpec`, runs `rowsToSeries → meanPerCell`, and draws. Metric picker lists scalar
  metrics plus one `dist:<family>` entry per distribution family; choosing a family reveals the sub-field select
  (default `mean`) and sets `gapWhenZeroColumn = ${family}.count` **unless** the sub-field is `count`.
- **`src/app/shell.ts`** — added the `Graph | Sweep` view-mode toggle (topbar), wrapped the existing
  Source/Network/Find/Replay sections in `#tsv-graph-controls`, added `#tsv-sweep-controls` and the `#tsv-chart`
  main container. The toggle shows/hides the two panel groups + two main containers and calls
  `sweepView.relayout()` when Sweep becomes visible (uPlot measures 0×0 while `display:none`). `applyTheme` now
  also calls `sweepView.setPalette`.
- **`src/app/styles.ts`** — CSS for the mode toggle, the per-mode panel groups, the chart host/plot/legend/empty,
  the sweep control rows, and `.u-legend`/`.u-axis` colours from `--tsv-*` so the legend re-themes.
- **`docs/design.md`** — new `## Sweeps view` section (both record kinds; non-finite + count:0 → gap with the
  `summarizeDistribution` reason; mean-per-cell and the documented decision *not* to scatter per-seed points;
  the uPlot notes). Intro, core-tier table row, and Testing section updated.

## Use cases for validation (what to test)

Headless (already auto-verified this run via a throwaway test against the real experiment files, since
`view.ts` only forwards to these pure functions):

- **jsonl ≡ csv agreement** on real files: `packages/tallysim/experiments/found-vs-oracle/out/depth-sweep.{jsonl,csv}`
  (discovery) and `.../route-existence/out/scalefree-realistic.{jsonl,csv}` (oracle) produce identical default
  series. Confirmed equal.
- **count:0 gap**: in the embedded sample, uniform `edgesPerNode=1` has one seed with `pathLength.count=0`; with
  the guard that seed is dropped so the cell's mean is `1.9` (the count:2 seed only); without the guard it is
  pulled to `0.95`. Confirmed.
- **default selection** of the sample: x = `network.params.edgesPerNode`, metric = `pRouteExists`, series =
  `[capacity, generator]` → the headline "route chance vs. connectivity, one line per generator" chart.

Manual (NOT run here — no browser in this environment; this is the real gap, see below). Reviewer should
`yarn dev` and, in **Sweep** mode:

- "Load sample sweep" → a two-line chart (uniform / scale-free) of pRouteExists rising with edgesPerNode.
- Switch metric to `pathLength (distribution)` → the sub-field select appears; `mean` default; the uniform x=1
  cell shows a point (not a spurious 0) and no line segment drops to 0.
- Load `depth-sweep.jsonl` then `depth-sweep.csv` (discovery sweep, x = `workload.depth`) → confirm the lines
  match between the two formats.
- Change x-axis to a metric (e.g. `meanDegree`), toggle series-by checkboxes, confirm the chart + legend redraw
  and re-theme on the light/dark toggle.
- A single-cell / all-gap selection → the chart's "nothing to plot" message; a deliberately corrupted JSONL line
  → a parse-error message in the sweep panel status (not the console).

## Known gaps / where to look hard (tests are a floor)

- **No real browser render happened.** `chart.ts` + `view.ts` are browser-only; their correctness past the pure
  pipeline (does uPlot actually draw, does the legend relocate, does the hidden→visible resize fire) is **only**
  covered by the build and the manual checklist above, which a human/CI must run. The prior run's claim that the
  chart "is done and verified" means type-checks + builds, not a pixel was seen.
- **x-axis picker offers every numeric column** — including all distribution sub-fields (a discovery sweep is
  ~50 of them). This matches the spec ("x may be any numeric column"), but the list is long. Parked as a
  `NOTE:` tripwire at `view.ts` `xOptions` — only act if the picker ever reads as noise.
- **Format sniff fallback** (`source.ts`): when neither extension nor the `{`/`generator` sniff settles it, a
  comma in the first line → CSV else JSONL. Heuristic; worth a sanity glance, though real files always have an
  extension or an unambiguous first line.
- **`alignSeries` is computed twice per draw** in `chart.ts` (`options()` and `draw()`), pre-existing from the
  prior partial implementation — harmless at planned sizes, not touched here.
- **Bundle size**: `vite build` warns the single chunk is >500 kB (sigma + graphology + uplot). Pre-existing,
  not introduced by this ticket; no code-splitting was added.
- **Live-run source tab is still unwired** (intended — the `tallysim-viewer-live-*` tickets left `src/live/`
  unintegrated; `3.66-tallysim-viewer-live-controls` is the follow-up). This ticket introduced the first mode
  switch with only `Graph | Sweep`; the live tab remains future work and the shell seam comment still marks it.
