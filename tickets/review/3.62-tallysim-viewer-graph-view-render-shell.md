## What was built

The graph tier's **renderer** and the **app shell** that drives it. The headless model + seeded worker layout
already existed (prior split of this ticket); this run added the parts that need a browser.

- **`src/graph/render.ts`** — `createGraphView(container, graph, palette) → GraphView`
  (`{ webglAvailable, setPalette, search, clearSelection, focusNode, destroy }`). sigma 4.0.6:
  - All styling in **reducers** (merged on top of sigma's built-in `DEFAULT_STYLES`): node = recessive neutral
    + label; edge capacity → thickness (1…5) + a sequential colour ramp from the **total swing**, log-normalised
    across a finite range computed **once** at setup.
  - **Unlimited edges** (`Infinity` in either direction) → distinct hue + a **fixed thickness (3) strictly below
    the finite max (5)** — the headline requirement that an `Infinity` tally can't look like a large finite one.
  - `head: 'arrow'` draws the stock → foil arrowhead; parallel tallies curve apart
    (`path:'straight'`, `parallelPath:'curved'`, `parallelSpread:0.35`); a zero-capacity direction still renders.
  - Hover + search ride sigma's **built-in state** (`isHovered`/`isHighlighted`) — left `customNodeState`/
    `customEdgeState` untouched for the replay ticket.
  - Hover **tooltips** (absolutely-positioned div in the container): node → `Entity {id}` + `degree`; edge →
    `tally {i}`, `stock {s} → foil {f}`, both directed caps (`∞` for Infinity).
  - `search(idText)` highlights + camera-animates to the node; **WebGL2 absent** → renders a message and returns
    an inert stub (`webglAvailable:false`, no-op methods) — no throw, no blank canvas.
- **`src/app/styles.ts`** — the shell CSS as a TS **string** (injected via `<style>`; a `.css` import would need
  a module `.d.ts` shim under NodeNext). Top bar + left panel + `position:relative` graph container; chrome
  colours are `--tsv-*` CSS variables the shell sets per theme.
- **`src/app/shell.ts`** — `mountShell(root)`: top bar (title + theme toggle), left panel (file picker, "Load
  sample" button, status area, network summary, search box), graph container. Load path: read file text →
  `indexTrace` inside `try/catch` (version/format errors go to the panel status, **not** the console) →
  `buildGraph` → `createGraphView` → `runLayout(seed: network.meta.seed)`. Tears down the prior view + worker on
  every load. Seam comments mark where the live-run and sweep tabs mount later.
- **`src/app/sample-network.ts`** — `sampleNetwork()`: a seeded ~3000-node scale-free network (lognormal caps,
  so the finite ramp is visibly exercised) behind the "Load sample" button.
- **`src/main.ts`** — replaced the stub; now just mounts the shell.
- **`docs/design.md`** — new **Graph tier**, **Edge-capacity encoding**, **Worker layout + seeding**, and
  **App shell** sections; Testing section updated to say the renderer/shell gate is build + manual check.

## Manual interactivity check — the real gate (run `yarn workspace tallysim-viewer dev`)

This is where review effort should go; none of it is covered by jest. Drive each case:

- **"Load sample" (~3000 nodes / ~6000 edges):** pan, zoom, hover nodes and edges (tooltips), type an entity id
  (e.g. `3`) and Enter (highlights + camera recentres). Confirm it stays **smooth** and that the force layout
  animates in *without freezing* pan/zoom — i.e. it's genuinely on the worker thread, not the main thread.
- **Degenerate sizes:** a 1-node and a 2-node network (hand-built trace, or a tiny generator), and an **edgeless**
  network — confirm no hang (the layout must settle immediately with no worker) and the view still draws.
- **Unlimited-only network:** every tally `capacity:{kind:'unlimited'}` — confirm every edge uses the distinct
  unlimited hue at the fixed moderate thickness, and that it reads as clearly *different* from a finite
  high-capacity edge (load a finite network alongside to compare).
- **Parallel + zero-capacity tallies:** a hand-built network with two tallies between one pair (they must curve
  apart, both arrowheads visible) and a tally whose one direction is `0` (the edge must still render with its
  arrowhead — zero ≠ missing).
- **Theme switch mid-view:** load a network, toggle light/dark — colours (surface, nodes, edges, tooltip chrome)
  must repaint with **no layout recompute** (node positions must not jump).
- **WebGL-absent:** disable WebGL2 (e.g. a browser flag) and load — a clear message should appear in the graph
  area, no thrown error, no blank canvas; search/theme become no-ops.
- **Bad file:** load a non-trace / wrong-version file — the parse error must appear in the panel's status area.

## Where to look hardest (correctness, not covered by tests)

- **Edge-capacity encoding math** (`render.ts`): `logNormalize` uses `Math.log1p`, clamps `[0,1]`, and returns
  `0.5` when the finite range is empty or degenerate (`min==max`). Sanity-check the tercile colour cut-offs and
  that `UNLIMITED_SIZE (3) < FINITE_SIZE_MAX (5)` holds as the invariant it's meant to be. A network with a huge
  capacity spread is the stress case for the log scale.
- **Load/teardown lifecycle** (`shell.ts`): repeated loads must not leak a sigma instance or a running FA2
  worker — `teardown()` calls `layout.stop()` then `view.destroy()` (`sigma.kill()`), then clears the container.
  Confirm no orphaned worker after several sample loads.
- **First-frame positions:** `createGraphView` is called *before* `runLayout` seeds positions (buildGraph inits
  x/y to 0). The design relies on sigma re-rendering from graphology's attribute-update events, so the seeded
  spiral should be the first painted frame (not an all-at-origin flash). Worth an eyeball on the sample load.
- **Search coordinate space:** `search` centres via `getNodeDisplayData(id).x/y` fed to `camera.animate` — the
  normalized-coords pattern from sigma's own example. Confirm it actually centres on the right node.
